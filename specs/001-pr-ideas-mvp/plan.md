# Implementation Plan: PR Ideas MVP

## Architecture Overview
Next.js 14 application with SQLite (Prisma) and Tailwind CSS.

## Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Database**: SQLite with Prisma
- **AI**: GPT-4o-mini (Vision)
- **Inbound**: AgentMail
- **Deployment**: Vercel

## Implementation Strategy
1. **Setup**: Initialize Next.js and Prisma.
2. **Inbound**: Setup the intelligence router.
3. **AI**: Implement the vision analysis and draft workflow.
4. **Gallery**: Build the public card-based UI.
5. **Engagement**: Implement likes and filtered comments.
6. **Deployment**: Deploy to Vercel.
